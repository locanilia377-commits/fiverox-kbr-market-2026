# FIVEROX — КБР и Нальчик

Исследование потенциальных партнёров по оклейке автомобилей и тонировке автомобильных стёкол. Срез: 17.11.2026.

- Вся КБР: 144 записи; 64 подтверждены по публикациям, 80 кандидатов; 118 с телефонами.
- Нальчик отдельно: 112 записей, 55 подтверждены по публикациям.
- Остальная КБР: 32 записи, 9 подтверждены по публикациям.
- 2ГИС: 105 ID, все карточки прочитаны подробно; 96 с телефонами. Яндекс: 71 ID после 22 запросов.
- Между картами объединено 31 совпадение, внутри 2ГИС — одна пара. Филиалы и разные адреса с общим телефоном сохранены для уточнения.

Полнота всей совокупности компаний не заявляется. Широкая выдача 2ГИС включает смежные услуги. Дополнительный запрос по Прохладному частично сверён относительно меняющегося счётчика. Услуги подтверждены публикациями; телефоны не проверялись звонком. Опубликованные суммы имеют ограничения объёма, доступности или оператора; заглушки 1 ₽ исключены.

Публикуются только проверенные статические файлы. Рабочие снимки браузера, закрытые данные, записи CRM и данные входа в репозиторий не включены.
